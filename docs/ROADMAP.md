# 路线图

路线按风险递增，而不是按功能数量递增。只有上一阶段的验收门通过，才进入
下一阶段。

## M0：本地研究闭环

状态：已初步完成。

- 严格策略配置和合成示例数据。
- 固定权重、整手和次日执行参考回测。
- 费用、滑点、换手率、暴露和最大回撤约束。
- 基准比较、人工订单建议和可审计运行产物。
- 零运行时依赖的 Python 3.9 CLI 和单元测试。

验收标准：

- 所有测试通过。
- 相同输入可重复运行。
- `live` 配置、缺失价格和未知配置字段均被拒绝。
- 不存在任何券商网络调用。

## M1：真实数据研究

状态：核心工程闭环已初步完成，个人政策确认和首批真实数据运营验收待完成。

已实现：

- 严格研究范围配置：市场、允许资产、期限、基准、复权口径和最大回撤。
- `DailyBarsProvider` 接口、AKShare ETF 日线适配器和数据许可清单。
- content-addressed 原始快照，记录抓取时间、供应商版本、请求和数据权利声明。
- content-addressed 清洗数据集，记录 as-of、复权口径和全部输入哈希。
- 交易日历、上市/退市、停牌、分红、拆股和合股数据契约。
- 数据质量报告、`available_at <= as_of` 过滤和文件完整性校验。
- 停牌成交阻断，以及现金、静态目标权重和基准比较。

进入 M2 前仍需：

- 由用户确认候选 CN ETF 范围、期限、最大可承受亏损和实际交易费率。
- 用有明确来源和使用权的数据替换合成 fixture，保存首批真实原始快照。
- 为交易所日历、证券主数据和公司行动增加供应商快照，而不是长期手工维护。
- 对易修订字段采购或构建真正的 vintage 数据；当前历史行情快照不能反证
  供应商在过去时点返回过相同值。

验收标准：

- 任意历史日期只能读取当时可获得的信息。
- 数据修订不会静默覆盖旧回测。
- 策略收益能与无策略基线、固定配置和基准进行比较。

上述三项已由离线 fixture 和自动化测试覆盖；真实数据验收以首批供应商快照的
质量报告为准。

## M2：独立回测验证

状态：离线研究内核和参数稳定性协议已完成，外部独立引擎对账待实现。

已实现的前置能力：

- PIT-safe 策略契约、固定权重与透明动量过滤策略。
- 稳定 decision ID、目标权重和决策证据产物。
- 强制按时间隔离的 train/validation/test 实验协议。
- 费用、税费、滑点和成交延迟压力场景。
- 趋势、震荡、暴跌恢复、阶段切换和停牌等确定性合成市场。
- Sortino、Calmar、回撤持续时间、跟踪误差和信息比率。
- 显式会计账本、公司行动入账和每日现金/持仓/NAV 对账。
- 未复权拆并股跨越待执行订单时 fail closed，避免沿用失效数量。
- 多个向前滚动的 train/validation/test 时间折。
- 邻近回看周期、阈值和调仓频率参数变体，以及 test 段敏感性摘要。
- 明确禁止自动选取事后最优参数，并声明当前没有逐折模型拟合。

仍需实现：

- 增加 VectorBT 快速研究适配器。
- 增加 RQAlpha 或目标量化平台的事件驱动复核。
- 对同一策略执行跨引擎结果对账。
- 对需要拟合的模型加入真正逐折训练，并增加市场阶段归因分析。

验收标准：

- 扣除费用后，核心结论不依赖单一回测引擎。
- 参数附近的小幅变化不会让结果从盈利跳到巨亏。
- 报告同时展示收益、回撤、换手率、容量和失败阶段。

## M3：模拟盘和对账

状态：离线状态机和恢复语义已完成，外部模拟柜台适配与真相源对账未实现。

已实现：

- 独立 `execution/paper.py`，不复用回测成交结果。
- 提交、确认、部分成交、完整成交、拒单和撤单状态机。
- 事件 ID、客户订单 ID 和成交 ID 幂等，柜台订单 ID 全局唯一，冲突内容
  fail closed。
- 原子状态快照、内容哈希、重启恢复、账户重建及事件历史回放对账。
- 资金不足、持仓不足、超额成交和非法状态迁移阻断。

仍需实现：

- 对接一个明确的外部模拟柜台，并以柜台查询结果作为恢复真相源。
- 增加行情过期、任务失败和风险冻结告警。
- 记录预期成交与实际模拟成交的偏差。

验收标准：

- 故障注入后没有重复订单。
- 重启后可以从券商/模拟柜台状态恢复，而不是相信本地缓存。
- 所有仓位差异都有告警和人工处理流程。

## M4：小资金人工确认

- 只生成待确认订单，不自动发送。
- 每次确认前重新读取账户、价格和风险限额。
- 设置策略资金上限和独立的一键停止开关。
- 向券商确认程序化交易权限、报备与接口要求。

## M5：自动执行

默认不进入。它需要单独的产品决策、合规确认和安全评审，不能通过增加一个
配置开关从 M4 顺手开启。
